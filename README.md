# LookMeant – AI-Powered Virtual Closet

**A smarter way to organize your wardrobe and discover your personal style.**

🚧 **Status:** In Active Development  
🌐 **Website:** https://lookmeant.com  
📱 **Platform:** iOS & Android (Flutter)

## Project Overview

LookMeant is an AI-powered virtual closet application designed to help users digitally organize their wardrobes, discover outfit combinations, and simplify everyday styling.

The application is being developed as a cross-platform mobile solution, combining modern UI/UX design with personalized styling features.

## Tech Stack

| Category | Technologies |
|---|---|
| Programming Language | Dart |
| Mobile Framework | Flutter |
| Backend Infrastructure | Supabase |
| Development Tools | VS Code, Xcode, Git, GitHub |
| Target Platforms | iOS and Android |

## Features

- Digital wardrobe organization
- Personalized onboarding and style preferences
- Cross-platform mobile interface
- AI-powered outfit recommendations (Planned)
- Complete-look styling suggestions (Planned)

## Engineering Highlights

- Building reusable Flutter widgets and responsive interfaces.
- Applying Dart null-safety and modular application development practices.
- Implementing image compression and optimization for mobile performance.
- Developing backend integration using Supabase.
- Designing with performance considerations for older mobile devices.

## Development Status

LookMeant is currently under active development. Features are being implemented and tested incrementally.

The main application repository is private. This public repository serves as a portfolio showcase documenting the project's design, development, and technical implementation.
